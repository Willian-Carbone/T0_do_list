INTERFACE EM TERMINAL PARA REGISTRO DE TAREFAS COM PERSISTENCIA DE DADOS

--> Execute arquivo Main.java

--> Arquivo tarefa.java contem a classe

--> Arquivo Metodos contem os static metodos para o funcionamento do código

--> tarefas.txt armazena tarefas

--> ao executar o aplicativo, uma lita das tarefas do dia é impresa no terminal, juntamente com o tempo que falta para seu prazo acabar
